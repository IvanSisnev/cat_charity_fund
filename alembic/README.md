# Работа с миграциями

## Создание сценария миграции:

```bash
alembic revision --autogenerate -m "<название миграции>" --rev-id 
<порядковый номер миграции>
```

## Проверка файла миграций

Необходимо проверить файл со сценарием миграции, в особенности 
корректность функций
`upgrade` и `downgrade`.

## Применение сценария миграции

```bash
alembic upgrade head 
```

> При необходимости отката примененных миграций необходимо ввести команду 
> `alembic downgrade base`
